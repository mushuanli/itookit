# @itookit/llm-ui

LLM 对话 UI：聊天界面、流式历史视图、会话编排（DAG）可视化与 Run 控制。

```bash
pnpm --filter @itookit/llm-ui typecheck
pnpm --filter @itookit/llm-ui build
pnpm --filter @itookit/llm-ui exec vitest run   # 本包未定义 test script
```
